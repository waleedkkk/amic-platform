# تحقق محلي لربط الصفقات الورقية بالإشارات

أضيف العمود الاختياري `paperTrades.signalId` في الترحيل `0022_brown_the_fallen.sql`، مع مفتاح أجنبي إلى `savedSignals.id` بسياسة `ON DELETE SET NULL` وفهرس مستقل. تحقق فحص قاعدة البيانات أن العمود من نوع `int` وقابل للقيمة الفارغة، وأن قاعدة الحذف المضبوطة للمفتاح الأجنبي هي `SET NULL`.

عند فتح مسودة صفقة من التحليل الفني أو توافق الأطر، تُحفظ نسخة الإشارة المصدرية أولًا ويُمرر معرّفها إلى المسودة ثم إلى إنشاء الصفقة. تتحقق طبقة قاعدة البيانات من ملكية الإشارة للمستخدم الحالي قبل التخزين، وتزيل الواجهة الربط عند تغيير الرمز أو البورصة يدويًا.

في النقد، تستخدم الصفقة المرتبطة `signalId` بالضبط وتُمرر للنموذج كـ `confirmed`. أما الصفقات القديمة غير المرتبطة فتستخدم فقط أقرب إشارة سابقة زمنيًا بالرمز والبورصة نفسيهما، وتُمرر كـ `guessed`. لا تُستخدم إشارة لاحقة أبدًا، وعند غياب مرشح يبقى النوع `none`.

نجحت اختبارات الوحدة المستهدفة (20 اختبارًا) ثم مجموعة الاختبارات الكاملة وفحص TypeScript وبناء الإنتاج وفحص `git diff --check`. بقي تحذير Rollup القديم حول حجم الحزمة فقط، وهو غير مانع. لم يُدفع أي تغيير ولم يُنشر إصدار جديد.
