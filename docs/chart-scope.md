# نطاق مخطط الأسعار في الإصدار الأول

## نتيجة التحقق من موفر السوق المضمّن

تمت مراجعة جميع مسارات مصدر `tradingview-mcp` المضمّن بحثًا عن أدوات OHLC والشموع التاريخية. تتوفر أدوات للعقود الآجلة تعيد **لقطات OHLCV حالية** للعقود الأمامية، مثل `futures_market_overview` و`futures_top_movers` و`futures_category_snapshot`. لا توفر هذه الأدوات سلسلة شموع تاريخية موحّدة لمختلف فئات الأصول أو تعاقداً عاماً من نوع `get_candles(symbol, timeframe, range)`.

لا تكفي لقطة OHLCV واحدة لرسم مخطط سعري زمني أو لتقديم تاريخ ظاهر للمستخدم. لذلك لا يرسم AMIC مسار سعر افتراضياً ولا يركّب نقاطاً مصطنعة، لأن ذلك قد يضلل المستخدم في سياق مالي.

## قرار الإصدار

يكتفي الإصدار الأول بمؤشرات RSI وMACD وBollinger والتوصية المسترجعة من التحليل الفني، مع حالات تحميل وأخطاء واضحة. سيُضاف موفر مخطط قابل للاستبدال فقط عند ربط مصدر فعلي للشموع التاريخية يحدد بوضوح الرمز والبورصة والإطار الزمني ومنطقة الترخيص.

| الشرط قبل إضافة المخطط | سبب الشرط |
|---|---|
| واجهة شموع حقيقية ومؤرخة | لتجنب اختلاق حركة سعرية أو خلط لقطة فورية بسلسلة زمنية. |
| دعم الرمز والبورصة والإطار الزمني | لضمان تطابق المخطط مع التحليل الفني المعروض. |
| سياسة استخدام وترخيص واضحة | لأن بيانات السوق قد تفرض قيوداً على العرض أو التخزين المؤقت. |
| اختبارات لتحويل البيانات والفجوات الزمنية | لتفادي عرض شموع مفقودة أو غير مرتبة. |
