# تحقق محلي لتلميحات السياق المترابط

أضيفت تلميحات عربية قابلة للوصول إلى عنوان «السياق المترابط»، والحالة النسبية، وشارة حالة كل أصل مرتبط، وخلاصة السياق، وبيان المصدر ووقت الجلب. تستعمل جميعها مكوّن التلميح الموحد، وتظهر بالتحويم أو التركيز، مع أزرار ذات تسميات `aria-label` عربية ومحتوى `RTL`.

توضح التلميحات أن السياق طبقة تفسيرية مستقلة وليست توصية أو تنفيذ تداول. كما تفسر الفرق بين الحالات المتوافقة والمتعارضة والسياقية وغير الحاسمة، وتبيّن أن وقت الجلب يخص لقطة البيانات من TradingView MCP.

أضيف في التحسين اللاحق فتح وإغلاق صريح بالنقر أو اللمس، مع حالة `aria-expanded` وربط `aria-controls` لمحتوى التلميح. أصبح المحتوى نفسه أوضح بصريًا: رأس ملوّن، أيقونة دلالة، نص بتباين أعلى، وإرشاد قصير يوضح التفاعل بالفأرة واللمس ولوحة المفاتيح. يظل التحويم والتركيز مدعومين كذلك.

نجح اختبار نصوص التلميحات، ثم مجموعة الاختبارات الكاملة وفحص TypeScript وبناء الإنتاج وفحص `git diff --check`. بقي تحذير Rollup القديم لحجم الحزمة فقط، وهو غير مانع. لم يُجرَ تحقق بصري داخل جلسة مستخدم مصادق عليها في هذه الدورة، ولم يُدفع أو يُنشر أي تغيير.
