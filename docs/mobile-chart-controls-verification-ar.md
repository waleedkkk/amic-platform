# التحقق من أدوات المخطط المبسطة للهاتف

تاريخ التحقق: 2026-08-22

نُشر الالتزام `cc590f1` بنجاح عبر GitHub Actions run `32595550412`. فُحصت صفحة التحليل في الإنتاج على عرض سطح المكتب؛ بقيت أزرار طبقات ICT الست وإعدادات ICT وزر ملء الشاشة مرئية كما هي، وهو السلوك المقصود للشاشات ابتداءً من نقطة `sm`.

يستخدم وضع الهاتف زر «الطبقات» الموحد مع عداد الطبقات النشطة، ويعرض مفاتيح تفعيل EMA Trend وBOS/CHoCH وBSL/SSL وOB/FVG وBUY/SELL وملخص ICT داخل قائمة اختيار واحدة. صُمم الزر باستخدام `sm:hidden` بينما تنتقل الأزرار الموسعة إلى `hidden sm:flex`، فيبقى الإطار الزمني وملء الشاشة خارج القائمة وبمتناول مباشر. يلزم تأكيد بصري نهائي على هاتف المستخدم لقياس اللمس وعرض القائمة الفعلي.

بعد إصلاح تركيب البوابة داخل عنصر ملء الشاشة، أُعيد تحميل صفحة التحليل في الإنتاج واكتملت بيانات المؤشرات والشموع دون خطأ عميل. سيجري التحقق التالي على أن النقر في وضع ملء الشاشة يفتح محتوى القائمة داخل عنصر الرسم نفسه.

في جلسة التحقق، تمت محاكاة قاعدة العرض الخاصة بالهاتف دون تعديل للشفرة المنشورة. ظهر زر «الطبقات 6/6» بدل شريط الأزرار الموسع، وبقيت إعدادات ICT وملء الشاشة متاحتين. سيُستخدم هذا الوضع لاختبار فتح القائمة بعد دخول ملء الشاشة.

تم الدخول إلى ملء الشاشة في جلسة التحقق ثم الضغط على «الطبقات 6/6». ظهرت قائمة «طبقات ICT» داخل مساحة المخطط، بما يشمل الخيارات الست وإعدادات ICT، وبذلك تأكد حل المشكلة التي كان فيها الزر ظاهرًا لكن محتوى القائمة غير مرئي.
