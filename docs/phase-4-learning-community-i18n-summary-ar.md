# ملخص المرحلة الرابعة: التعلم والخصوصية واللغات

## الملخص اليومي للسوق

أضيف ملخص يومي اختياري داخل صفحة التقويم الاقتصادي. يستدعي الخادم أدوات `market_snapshot` و`top_gainers` و`top_losers` من TradingView MCP القائم، ثم ينشئ نصًا تعليميًا يبين وقت الجلب. لا يُرسل النص إلى تيليغرام إلا إذا فعّل المستخدم الاشتراك وحفظ إعداد تيليغرامه. يمنع سجل التسليم التكرار لنفس المستخدم في اليوم نفسه عند إعادة محاولة المعالج المجدول.

سيعمل المسار المحمي `/api/scheduled/daily-market-digest` بعد النشر فقط، وتُنشأ له مهمة Heartbeat مستقلة عند اكتمال التحقق من عنوان الإنتاج. لا توجد حلقة زمنية داخل عملية Node.

## نقد الصفقات الورقية

أضيفت صفحة «نقد الصفقات» المنفصلة، ويصل إليها المستخدم اختياريًا بعد إغلاق صفقة ورقية. يرسل الخادم للنموذج بيانات الصفقة المغلقة والإشارة المطابقة المتاحة فقط، ويطلب استجابة JSON منظمة حول الالتزام بالخطة والتوقيت وما تم جيدًا وما يحتاج إلى تحسين وخطوات تعليمية تالية. يمنع نص الطلب صراحةً تقييم مشاعر المستخدم أو شخصيته أو دوافعه، ولا يقدم توقعًا سعريًا أو أمرًا لفتح أو إغلاق صفقة.

يحفظ النقد في جدول خاص مرتبط بمالك الصفقة، ويجري كل استعلام بشرط `userId`. لا يوجد مسار مشاركة عام للنقد ولا يُعاد البريد أو سجل المحادثة إلى النموذج.

## مراجعة الخصوصية: لوحة الصدارة

تبدأ المشاركة في لوحة الصدارة بحالة معطلة. عند الرغبة في المشاركة، يختار المستخدم اسم عرض أو يفعّل وضع «متداول مجهول». لا تستعلم واجهة الصدارة عن البريد أو اسم الحساب أو معرف المستخدم أو البورصة أو الرموز التي يتداولها أحد، بل تعرض اسمًا مختارًا أو مجهولًا ومقاييس مجمعة للصفقات الورقية المغلقة فقط.

| العنصر | سياسة الخصوصية |
|---|---|
| الاشتراك | إيقاف افتراضي وتفعيل صريح من المالك. |
| الاسم | اسم عرض محدود إلى 40 حرفًا، يمنع الروابط وصيغ البريد، ويمكن حجبه تمامًا. |
| البيانات المعروضة | عدد الصفقات المغلقة ونسبة الفوز والعائد النسبي والربح/الخسارة المجمع. |
| البيانات المحجوبة | البريد ومعرف المستخدم وسجل الصفقات الفردية والرموز والبورصات والملاحظات والنقد الذكي. |
| الانسحاب | تعطيل المشاركة يخفي الملف من الاستعلامات اللاحقة فورًا. |

## أساس i18n

أضيف سياق لغوي خفيف بلا مكتبة إضافية، ويحفظ اختيار المستخدم في `localStorage` باسم `amic:language` ويضبط `lang` و`dir` على عنصر الصفحة. تُرجمت عناصر التنقل الشائعة، والتنبيه المسؤول، وإجراء تسجيل الخروج، وصفحة التقويم الاقتصادي بالكامل بين العربية والإنجليزية. لا يدعي هذا التغيير ترجمة التطبيق كله؛ الصفحات الأخرى تبقى عربية حتى تُنقل نصوصها تدريجيًا إلى المفاتيح نفسها.

| الخطوة التالية | أسلوب التوسعة |
|---|---|
| صفحة جديدة | إضافة المفاتيح المتوازية إلى `client/src/lib/i18n.tsx` ثم استدعاء `t("key")` داخل المكوّن. |
| نصوص ذات متغيرات | إضافة دالة تنسيق صغيرة فوق القاموس بدل دمج السلاسل في المكوّن. |
| صفحات كاملة | البدء بالعناوين والإجراءات وحالات التحميل والخطأ، ثم النصوص الطويلة. |
| مراجعة RTL/LTR | اختبار الصفحة المختارة في اللغتين، خصوصًا عناصر الجدول والمحاور والأرقام. |

## التحقق

نجحت اختبارات الملخص اليومي والنقد المنضبط وملف الصدارة وi18n، كما نجحت اختبارات المشروع الكاملة: **190 اختبارًا ناجحًا** مع **4 اختبارات حية متجاوزة عمدًا**، ونجح بناء الإنتاج محليًا. بقيت اختبارات تفاعل المستخدم مع تيليغرام والنموذج وMCP الحي إلى ما بعد النشر لأن المعالجات تعتمد على خدمات الإنتاج الداخلية.
