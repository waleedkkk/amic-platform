# ملخص المرحلة الثالثة: مختبر الاستراتيجيات وإعادة تشغيل السوق

## واجهة الباكتيست

أضيفت صفحة «اختبار الاستراتيجيات» كواجهة محمية تستدعي أدوات `backtest_strategy` و`compare_strategies` و`walk_forward_backtest_strategy` من خدمة TradingView MCP الموجودة أصلًا؛ لم يُنشأ MCP جديد. تقيد الواجهة الرمز بترميز Yahoo Finance، وتعرض اختيار الاستراتيجية والمدة والإطار ورأس المال والعمولة والانزلاق، ثم تعرض المقاييس الناتجة ومنحنى الأداء وسجل الصفقات المغلقة أو ترتيب الاستراتيجيات عند المقارنة.

| الضابط | التطبيق |
|---|---|
| المصدر | تمرير الطلب من الخادم فقط إلى TradingView MCP؛ لا يرى المتصفح عنوان خدمة MCP الداخلي. |
| الاستراتيجيات | تسع استراتيجيات كما يعرّفها MCP، منها RSI وBollinger وMACD وSupertrend وTriple EMA. |
| واقعية المدخلات | العمولة والانزلاق يمثلان تكلفة لكل جانب ويقيدان بين 0 و100%. |
| رسالة المخاطر | الواجهة توضح أن النتيجة تاريخية وتعليمية ولا تنفذ صفقات ولا تضمن أداءً مستقبليًا. |

## وضع AMIC Replay

أضيفت صفحة «إعادة تشغيل السوق» لجلسة تاريخية تَعرض الشموع خطوة بخطوة. تحتفظ دالة `getReplayVisibleCandles` فقط بالشموع من بداية العينة حتى آخر شمعة مرئية، ويمرر الرسم ومحرك Confluence هذه النافذة فقط. لا يستخدم Replay بثًا حيًا ولا يرسم أي شمعة لم تصل إليها الجلسة بعد. يمكن للمستخدم التحرك إلى الشمعة السابقة أو التالية أو إعادة الجلسة إلى نقطة البداية، مع عرض إشارة Confluence والعوامل المحسوبة من التاريخ المرئي.

## التحقق

أضيف اختبار للتحقق من عقد واجهة الباكتيست، واختبار راوتر يثبت تمرير سجل الصفقات ومنحنى الأداء إلى أداة MCP، واختبار Replay يثبت أن الشموع التي بعد المؤشر المرئي لا تصل إلى العرض أو الحساب. نجحت المجموعة الكاملة محليًا: **184 اختبارًا ناجحًا** و**4 اختبارات حية متجاوزة عمدًا**، كما نجح بناء الإنتاج. لم يمكن تنفيذ اختبار MCP حيًا في بيئة التطوير لأن عنوان خدمة MCP الداخلي غير متاح فيها؛ سيُنفذ بعد النشر ضمن الحاوية التي تضم الخدمة الحالية.
