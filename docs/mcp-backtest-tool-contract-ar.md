# عقد أدوات الباكتيست في TradingView MCP

تستخدم منصة AMIC خدمة `tradingview-mcp` القائمة فقط. يحدد المصدر الأصلي ثلاث أدوات مناسبة للواجهة: `backtest_strategy` لاختبار استراتيجية واحدة، و`compare_strategies` لترتيب الاستراتيجيات التسع، و`walk_forward_backtest_strategy` لتقسيم التدريب والاختبار ورصد فرط الملاءمة. تدعم أدوات الباكتيست فترتي `1d` و`1h`، ومددًا تبدأ من شهر وتصل إلى سنتين، وتعيد عند الطلب سجل الصفقات ومنحنى رأس المال. [1]

| الأداة | المدخلات التي تستخدمها AMIC | النتيجة المعروضة |
|---|---|---|
| `backtest_strategy` | الرمز، الاستراتيجية، المدة، رأس المال، العمولة، الانزلاق، الإطار، سجل الصفقات، منحنى الأداء | المقاييس، منحنى الأداء، وآخر الصفقات المغلقة. |
| `compare_strategies` | الرمز، المدة، رأس المال، الإطار | ترتيب الاستراتيجيات حسب الأداء التاريخي. |
| `walk_forward_backtest_strategy` | الرمز، الاستراتيجية، المدة، رأس المال، التكاليف، وتقسيم التدريب/الاختبار | حكم قابلية التعميم ورصد فرط الملاءمة. |

لا تُعامل النتائج بوصفها نصيحة مالية أو أمر تداول، ولا تنفذ AMIC أي عملية تداول تلقائيًا.
