# خيارات البث الحي متعدد الأصول لـ AMIC

تحتاج AMIC إلى مزود مرخّص للبث الحي كي لا تعتمد الأسهم وFX والمعادن على تحديثات دورية. يجب أن يبقى مفتاح المزود على الخادم فقط، وأن يحوّل الخادم رسائل المزود إلى عقد موحد للشموع والتحديثات الجزئية قبل إرسالها للواجهة.

## خيار مرشح: Twelve Data

تذكر وثائق Twelve Data أنها تغطي الأسهم وFX وETF والعملات المشفرة والسلع عبر أسواق عالمية، وأن إنشاء حساب ومفتاح API مطلوبان للوصول إلى REST وWebSocket. كما تذكر صفحة بيانات الفوركس أنها تغطي أزواج العملات والمعادن الثمينة في الوقت الفعلي ضمن عروض الخدمة المناسبة. لذلك يصلح كمرشح واحد لتوحيد الأسهم وFX والمعادن، بعد مراجعة خطة الاشتراك والرموز المطلوبة قبل أي ربط إنتاجي.

المصادر الرسمية: [نظرة عامة على وثائق Twelve Data](https://twelvedata.com/docs/introduction/overview)، [بيانات السوق](https://twelvedata.com/market-data)، [بيانات الفوركس والمعادن](https://twelvedata.com/forex).

## بدائل للمقارنة

- يوفّر Finnhub واجهات WebSocket للأسهم وFX والعملات المشفرة، وتختلف تغطية الوسطاء والفئات وفق الخطة: [وثائق WebSocket](https://finnhub.io/docs/api/websocket-trades).
- يوفّر Massive/Polygon بثًا حيًا تفصيليًا للأسهم؛ يجب التحقق من نطاقات FX والمعادن وترخيص كل خطة قبل الاعتماد عليه: [وثائق بث الأسهم](https://massive.com/docs/websocket/stocks/overview).

## قرار مطلوب قبل الربط

يختار مالك المنصة مزودًا وخطة بيانات، ثم يوفر مفتاح API في إعداد سري للخادم. بعد ذلك تُنفّذ طبقة موحدّة تعزل رموز المزود، تحدّ من الاتصالات، وتعرض «مباشر» فقط عندما تكون الرسالة واردة بالفعل، مع الإفصاح عن التأخر أو المصدر البديل عند الانقطاع.
