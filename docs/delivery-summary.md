# ملخص تسليم AMIC

## النطاق المنجز

يتضمن المشروع منصة عربية داكنة ومتجاوبة للتحليل المالي، مع لوحة السوق، والتحليل الفني، وتحليل توافق الأطر، وماسح السوق، والتداول الورقي، وسجل الإشارات، ومساعد تفسيري بالذكاء الاصطناعي. لا تولّد الواجهة أسعاراً أو عوائد مصطنعة؛ إذ تعرض حالة انتظار أو خطأ إلى أن تتصل بخدمة السوق الحقيقية.

تستخدم طبقة الخادم جسر MCP داخلياً للتواصل مع مشروع `tradingview-mcp` المضمّن. الإصدار المدمج يعلن 38 أداة، وتُعرض الأدوات ديناميكياً لخادم Node.js، بدلاً من إعادة بناء خادم MCP أو تثبيت مجموعة أدوات ثابتة في الواجهة.

| المجال | حالة التسليم |
|---|---|
| عزل بيانات المستخدم | مفاتيح مرجعية وعمليات قراءة/كتابة مرتبطة بـ `userId` للصفقات والإشارات وقوائم المراقبة. |
| التداول الورقي | فتح وإغلاق المراكز، وحساب الربح والخسارة باستخدام حسابات عشرية دقيقة. |
| بيانات السوق | لوحة الرابحين والخاسرين، التحليل الفني، الأطر المتعددة، والماسح، مع تخزين مؤقت قصير للقراءات العامة. |
| الذكاء الاصطناعي | دردشة تفسر التحليل وتوضح أن المحتوى معلوماتي وتعليمي وليس توصية شخصية. |
| الحاويات | `docker-compose.yml` يشغّل Node.js وPython/MCP على شبكة داخلية، من دون نشر المنفذ 8000. |

## نتيجة التحقق

نجح فحص TypeScript، ونجحت 12 حالة اختبار Vitest عبر 5 ملفات. تغطي الاختبارات حساب الربح والخسارة، وملكية حساب التداول الورقي، وصحة مدخلات التحليل، والتخزين المؤقت، وعقد جسر MCP. كما تمت معاينة صفحات التحليل الفني والتداول الورقي والمساعد على الهاتف بعد إصلاح الاقتطاع الأفقي.

## التشغيل التالي

أنشئ أو أرفق خادماً دائماً، وانسخ المشروع إليه، ثم اتبع [`deployment.md`](./deployment.md). يجب تعريف أسرار البيئة وقاعدة بيانات MySQL أو TiDB على الخادم، وتشغيل `docker compose config --quiet` وترحيل قاعدة البيانات قبل `docker compose up -d`.

> لا يضع AMIC أوامر لدى وسيط حقيقي. التداول الورقي منفصل لكل مستخدم، ويُستخدم للأغراض التعليمية والمحاكاة فقط.
