# تحقق محلي لإعدادات ألوان وشفافية طبقات الشارت

أضيفت تفضيلات `layerStyles` إلى عقد تفضيلات الشارت المحفوظة مسبقًا لكل مستخدم. تشمل التفضيلات 15 لونًا لخطوط SMA وEMA والدعم والمقاومة ومناطق العرض والطلب وخطوط ومناطق وإشارات ICT والسيولة وأعمدة الحجم، إضافة إلى خمس درجات شفافية للمسارات والمستويات والمناطق والإشارات والحجم.

تطبّع طبقة العقد الألوان إلى صيغة `#RRGGBB` وتستعيد القيمة الافتراضية عند أي إدخال غير صالح. كما تقيد الشفافية بين 15% و100%، وتحوّل اللون والشفافية إلى صيغة RGBA قبل الرسم. تستمر الصفوف القديمة في العمل عبر إضافة القيم الافتراضية عند القراءة.

تظهر لوحة «مظهر طبقات الشارت» من أدوات المخطط على سطح المكتب ومن قائمة الطبقات على الهاتف. يمكن اختيار اللون وعرض رمزه، وضبط الشفافية بمنزلقات، ثم استعادة كل القيم الافتراضية. كل تعديل يُحفظ ضمن تفضيلات الحساب الحالي ويُعاد تطبيقه على الشارت.

نجحت اختبارات التطبيع والتحويل والترحيل للتفضيلات القديمة، ثم مجموعة الاختبارات الكاملة وفحص TypeScript وبناء الإنتاج وفحص `git diff --check`. بقي تحذير Rollup المعروف لحجم الحزمة فقط، وهو غير مانع. لم يُجرَ تحقق بصري داخل جلسة مستخدم مصادق عليها، ولم يُدفع أو يُنشر أي تغيير.
