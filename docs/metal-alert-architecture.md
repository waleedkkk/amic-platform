# تصميم تنبيهات المعادن

تعمل التنبيهات على مستويين متكاملين. يحتفظ كل مستخدم بتنبيه مستقل للذهب أو الفضة، مع شرط تجاوز صعودي أو هبوطي وسعر هدف. يفحص عامل مجدول مشترك أسعار عقود COMEX الفعلية، ويعطّل التنبيه فور إطلاقه لتجنب الإرسال المتكرر. تُنشأ في الوقت نفسه رسالة داخل AMIC تخص صاحب التنبيه وحده، وتُرسل رسالة تيليغرام إن كان المستخدم قد فعّل رقم دردشته.

| العنصر | القرار |
| --- | --- |
| مصدر السعر | GC=F للذهب وSI=F للفضة من مزود الشموع الحالي |
| النطاقات المرئية | نقاط ساعية لليوم ونقاط يومية للأسبوع |
| التحليل المفصل | مخطط `CandlestickChart` الحالي داخل نافذة بطاقة المعدن، مع مؤشراته وطبقاته |
| التنبيه | مرة واحدة عند تجاوز السعر الهدف في الاتجاه المحدد، ثم يُوقف تلقائيًا |
| التنبيه الداخلي | سجل غير مقروء خاص بالمستخدم، يُعرض ويُعلَّم مقروءًا من الأداة نفسها |
| تيليغرام | رمز بوت على الخادم فقط، ومعرّف دردشة اختياري محفوظ لكل مستخدم |
| المتابعة | Heartbeat مشترك كل خمس دقائق؛ لا مؤقتات داخل عملية الويب |

يتطلب تشغيل قناة تيليغرام إدخال رمز البوت في متغير `TELEGRAM_BOT_TOKEN`. تعتمد الإرساليات على واجهة Telegram Bot API الرسمية عبر HTTPS، ولا يصل الرمز أو أي بيانات اعتماد إلى المتصفح.
