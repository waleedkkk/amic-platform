# بحث مصادر بيانات الذهب والفضة الاحتياطية

## نتائج أولية

| المصدر | النتيجة | الملاءمة للمخطط |
|---|---|---|
| Stooq | صفحة `XAUUSD` تعرض تاريخًا يوميًا بأعمدة Open وHigh وLow وClose وخيار تنزيل CSV، لكن نقطة CSV البرمجية أعادت تحدي JavaScript للتحقق من المتصفح أثناء الاختبار الخادمي. | لا يعتمد عليه احتياطًا خادميًا حتى تتوفر واجهة رسمية لا تتطلب تحدي متصفح. |
| Alpha Vantage | التوثيق يعرض نقاط Commodities للذهب والفضة الفورية والتاريخية، مع الحصول على مفتاح API مجاني. | يصلح احتياطًا اختياريًا لأسعار مرجعية وتاريخ منخفض التردد، وليس بديلًا وحيدًا لشموع intraday. |
| FRED / سلسلة تثبيت لندن | أعلنت FRED إزالة بيانات IBA، ومنها أسعار الذهب والفضة اليومية في لندن، في 31 يناير 2022. | غير مناسب كاحتياط تشغيلي لهذه السلاسل المحددة. |

## التصميم المقترح لسلسلة الاحتياط

| الطبقة | المصدر | الوظيفة | شرط الاستخدام |
|---|---|---|---|
| 1 | Twelve Data | شموع OHLC الأساسية للرمزين `XAU/USD` و`XAG/USD`. | متاح حاليًا، ويستخدم ما دام يعيد تاريخًا صالحًا. |
| 2 | Yahoo Finance | شموع عقود المعادن المستمرة: `GC=F` للذهب و`SI=F` للفضة. | الاحتياط الحالي عند فشل المصدر الأساسي أو نقص التاريخ. |
| 3 | آخر تاريخ سليم مخزّن | إبقاء آخر شموع مكتملة حتى 24 ساعة إذا تعطلت الشبكة أو المصدران. | يعرض بوضوح باعتباره بيانات قديمة مع وقت المصدر، ولا يُقدّم كبيانات حية. |
| 4 اختياري | Alpha Vantage أو مزود معادن بمفتاح مجاني | سعر مرجعي يومي والتحقق من معقولية آخر إغلاق، لا اختراع شموع OHLC. | يفعّل فقط بعد إضافة مفتاح المستخدم؛ لا بطاقة مطلوبة ضمن الخطط المجانية التي يوفرها المزود. |

> لا يجوز تحويل سعر مرجعي واحد إلى شمعة مصطنعة. إن لم يعد مزود احتياطي ببيانات Open وHigh وLow وClose صالحة، يستخدم النظام آخر تاريخ شموع صحيح مع شارة **بيانات قديمة** بدل عرض شارت مضلل.

## ضوابط الدمج المقترحة

1. إنشاء واجهة `MetalCandleProvider` منفصلة عن مزودي الكريبتو والأسهم، وتضم تحويلات رموز خاصة بكل مزود.
2. تجربة المزودين بترتيب واضح، مع فحص أن التاريخ يحوي شمعتين على الأقل وأن كل شمعة تحقق `low ≤ open/close ≤ high` وأن الزمن تصاعدي.
3. حفظ مصدر كل استجابة ووقت جلبها وسبب التحويل إلى الاحتياط، مع شارة ظاهرة في المخطط للمصدر وحالة الحداثة.
4. استخدام قاطع دائرة قصير لكل مزود فاشل لتفادي إعادة طلبه مرارًا؛ ثم إعادة المحاولة بعد مهلة محددة.
5. اختبار سيناريو نجاح كل مزود، وفشل Twelve Data، وفشل Yahoo، واستعمال البيانات القديمة، ورفض بيانات OHLC غير السليمة.

## نطاق التنفيذ التالي

لا تحتاج الطبقات الثلاث الأولى إلى بطاقة أو مزود مدفوع. إضافة Alpha Vantage أو مزود معادن آخر تكون اختيارية كمرجع سعر مستقل وتتطلب مفتاح API مجاني فقط، ولا ينبغي أن تصبح شرطًا لعرض الشموع.
