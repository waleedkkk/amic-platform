# تدقيق تبسيط تجربة المستخدم — دفعة محلية

## نطاق المراجعة

ركزت هذه الدفعة على المسار الأكثر شيوعًا: **اختيار أصل → فهم القراءة → مراجعة المخاطر → محاكاة صفقة**. وشملت التنقل العام، نبضة السوق، التحليل الفني، التداول الورقي، ومساعد AMIC.

## مصادر الإرباك التي عولجت

| الموضع | الملاحظة | الإجراء المحلي |
| --- | --- | --- |
| التنقل الجانبي | قائمة مسطحة طويلة تجمع العمل اليومي والأدوات الثانوية والإدارة | تجميع الروابط في: السوق والتحليل، المحاكاة والمتابعة، أدوات إضافية، والإدارة للمديرين |
| نبضة السوق | بطاقات أعداد كبيرة تسبق القوائم التي تعرض النتيجة نفسها في سياق أوسع | استبدالها بملخص سريع مضغوط يوضح حالة الأقسام فقط؛ تبقى التفاصيل في القوائم |
| التحليل الفني | تكرار قيم المؤشرات في بطاقات المؤشرات ثم مجددًا داخل ملخص القراءة | الإبقاء على القيم في البطاقات وإزالة النسخة الثانية؛ أصبح الملخص يشرح الاتجاه والخطوة التالية فقط |
| التداول الورقي | مفاهيم الخطة والمخاطر تظهر قبل وجود تعريف مختصر عند الحاجة | إضافة شروح عند الطلب للاتجاه ووقف الخسارة وجني الربح ونسبة العائد إلى المخاطرة |
| المساعد الذكي | شرح ثابت طويل نسبيًا قبل الدردشة | توجيه مباشر للبداية مع شروح عند الطلب لمصدر البيانات وذاكرة المحادثة |

## مبادئ التنفيذ

> التلميح السياقي يظهر بالنقر أو بلوحة المفاتيح، لا بالمرور فقط؛ وهو ملائم للهاتف وواجهة RTL. لا تُخفى العناصر الأساسية وراء التلميحات.

لا تغيّر هذه الدفعة مصادر البيانات أو منطق التداول الورقي أو عزل المستخدمين. لم يُجرَ تحقق بصري داخل صفحات مصادق عليها، لأن المراجعة الحالية لا تستخدم جلسة مستخدم أو مدير.

## ما لم يُعالج بعد

تبقى مراجعة الصفحات الثانوية، وبخاصة التوافق متعدد الأطر، التنبيهات، الماسح، الاختبارات الخلفية، وإعادة التشغيل، مرحلة لاحقة. كما يلزم تحقق بصري مصادق عليه قبل اعتماد أي نشر.
