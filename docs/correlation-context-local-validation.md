# تحقق محلي لطبقة السياق المترابط

تُصنّف طبقة السياق المترابط الأصل إلى معدن أو فوركس أو كربتو أو سهم، ثم تختار فقط أصولًا لها علاقة اقتصادية أو هيكلية معلنة في الخريطة. تشمل الأمثلة المعادن مع الدولار والعائد والمعدن المقابل وقطاع التعدين، والفوركس مع الدولار والعائد ومع سلعة مرتبطة بالدولار الأسترالي أو الكندي عند انطباق العلاقة، والكربتو مع بيتكوين وإيثيريوم وهيمنة بيتكوين وNasdaq 100.

تستخدم الطبقة `coin_analysis` عبر TradingView MCP القائم لكل أصل مرتبط، وتحتفظ بطابع الجلب والمصدر لكل قيمة. عند فشل أصل واحد، يُسجّل السبب تشخيصيًا ويُستبعد ذلك الأصل فقط؛ ولا يوقف هذا التحليل الأساسي. كما لا يُطلب السياق عند تفعيل احتياط تاريخ الشموع بعد تعذر TradingView MCP لتجنب إعادة محاولات شبكة غير لازمة.

يُنتج التقييم حالة وصفية فقط: `توافق قوي` أو `توافق متوسط` أو `توافق ضعيف` أو `تعارض سياقي` أو `بيانات غير كافية`. ويُبنى على تطابق حركة الأصل المرتبط مع العلاقة المتوقعة (متزامنة أو عكسية)، لا على رقم ثقة مصطنع. يظهر قسم مستقل بعنوان «السياق المترابط» في التحليل الفني مع الأصول المتاحة وتغيرها ومصدرها ووقت جلبها وخلاصة تفسيرية غير توصوية.

تم فحص إعدادات التكامل قبل التنفيذ: خادم TradingView MCP مستخدم ضمن التطبيق القائم، بينما موصل Alpha Vantage موجود لكنه غير مفعّل ولم يُعدّل. نجحت اختبارات اختيار الأصول حسب الفئة، والتوافق (ذهب صاعد ودولار هابط)، والتعارض، وبقاء التحليل الأساسي عند فشل أصل مرتبط. كما نجحت مجموعة الاختبارات الكاملة وفحص TypeScript وبناء الإنتاج وفحص `git diff --check`. ظهر تحذير Rollup المعروف لحجم الحزمة فقط، وهو غير مانع. لم يُدفع أي تغيير ولم يُنشر إصدار جديد.
