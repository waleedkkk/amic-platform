# خارطة طريق تطوير التحليل الفني للمعادن والعملات

## الوضع الحالي

يقدّم قسم التحليل الفني حاليًا اختيارًا للرمز والبورصة والإطار الزمني، ومخطط شموع مع طبقات المتوسطات والمستويات والمناطق والبنية السوقية، إضافة إلى RSI وMACD وBollinger، وقراءة متعددة الأطر، ومسودة تداول ورقية بمستويات مخاطرة مقترحة. كما أصبح مسار شموع الذهب والفضة يبدّل صراحة بين Twelve Data ثم Yahoo Finance عند الحاجة.

الهدف التالي ليس زيادة عدد المؤشرات بلا تمييز، بل جعل قراءة الذهب والفضة وأزواج العملات **أوضح مصدرًا، أكثر اتساقًا عبر الأطر، وأسهل تحويلًا إلى خطة تداول ورقية قابلة للمراجعة**.

## الأولويات المقترحة

| الأولوية | المبادرة | النتيجة للمستخدم | نطاق التنفيذ |
|---|---|---|---|
| P0 | بطاقة حالة بيانات الأصل | يعرف المستخدم المصدر، وقت آخر شمعة، هل السعر حي أم مؤجل، ولماذا تم التحويل إلى Yahoo. | إضافة وصف مصدر/حداثة/احتياط قرب المخطط، وسجل تقني مختصر دون كشف أسرار. |
| P0 | ملفات أصل مخصصة للذهب والفضة والفوركس | فواصل مناسبة لكل سوق وتحويل صحيح للرموز والدقة والسعر. | إعدادات موحدة للرمز: الدقة، رمز Yahoo، مزود البث المتاح، نطاقات الشموع، وملصق الأصل. |
| P1 | قياس التذبذب بالمقياس الصحيح | مستويات وقف وجني أرباح قابلة للفهم بين الذهب والفوركس. | عرض ATR كنسبة وبالنقاط؛ تحويل فارق السعر إلى نقاط/pips حيث يمكن تحديد زوج العملات بثقة. |
| P1 | بنية سعرية متعددة الأطر | يمنع الاعتماد على إشارة 15 دقيقة معاكسة لاتجاه 4 ساعات أو يومي. | لوحة توافق 15m/1h/4h/1D مع الاتجاه والبنية والزخم ودرجة الاتفاق، لا توصية تنفيذية تلقائية. |
| P1 | مستويات ومناطق موثقة المصدر | يعرف المستخدم إن كان الدعم/المقاومة من swing أو متوسط أو نطاق أو منطق ICT. | توسيع تسميات المخطط ونافذة التفاصيل لإظهار مصدر كل خط ودرجة الثقة وتاريخ اكتشافه. |
| P2 | سياق خاص بالمعادن والعملات | يربط قراءة الأصل بالسياق الذي يختاره المستخدم بدل ازدحام الشاشة. | بطاقات اختيارية: DXY، عائد السندات، زوج مرجعي أو نسبة الذهب إلى الفضة؛ تعرض الارتباط ولا تدّعي السببية. |
| P2 | تقويم وأحداث حسب الأصل | يساعد على رؤية أحداث الاقتصاد الكلي القريبة قبل قراءة الدخول. | فلتر للتقويم: أحداث الدولار للذهب وXAUUSD، وأحداث عملة الأساس/التسعير لأزواج الفوركس. |
| P2 | تنبيهات بنية ومناطق | ينبه فقط عند منطقة اختارها المستخدم أو عند كسر بنية مكتشف. | إعادة استخدام نظام التنبيهات الحالي مع قواعد خاصة بالرمز والإطار والمنطقة. |
| P3 | Replay وBacktest لمجموعة رموز المعادن/الفوركس | يختبر المنهج على التاريخ قبل الاعتماد على انطباع بصري. | قوالب اختبار XAUUSD وXAGUSD وأزواج الفوركس، مع فصل جودة البيانات عن نتيجة الاستراتيجية. |

## ترتيب التنفيذ العملي

### المرحلة الأولى: الثقة في البيانات

ينفذ أولًا ملف الأصل وبطاقة حالة بيانات الأصل. يعرض المخطط بوضوح اسم المصدر الفعلي، وقت آخر جلب، حالة البث أو التأخير، وحالة الاحتياط. عند استخدام بيانات تاريخية بعد فشل المصدر الأساسي، تظهر شارة **«احتياط Yahoo»** بدل تقديمها كبيانات لحظية.

### المرحلة الثانية: القراءة الفنية المتسقة

تضاف لوحة توافق متعددة الأطر، ثم مستويات ذات مصدر واضح وقياس ATR بالنقاط أو pips. بهذه المرحلة يصبح الرسم والإشارة ومسودة الصفقة متصلة بسياق واحد: اتجاه أكبر، منطقة محددة، ومخاطرة قابلة للمراجعة.

### المرحلة الثالثة: السياق والتنبيهات

يُتاح للمستخدم تفعيل بطاقات سياقية وفق ما يتابعه؛ الذهب يمكن أن يجاوره DXY أو الفضة، والفوركس يمكن أن يجاوره زوج أو مؤشر يختاره المستخدم. ثم تضاف التنبيهات على المناطق أو تحولات البنية، لا على تنبؤات سعرية عامة.

### المرحلة الرابعة: التقييم التاريخي

تُنشأ قوالب Replay وBacktest منفصلة للمعادن والفوركس، مع بيان مصدر الشموع وحدودها. لا ينبغي مقارنة نتائج أصلين مختلفين بلا توحيد الإطار والمخاطر.

## الضوابط غير القابلة للتنازل

| الضابط | التطبيق |
|---|---|
| دقة المصدر | لا تُصنع شمعة من سعر واحد، ولا يُعرض التاريخ القديم كأنه حي. |
| الخصوصية | إعدادات الأصول والتنبيهات ومسودات الصفقات مرتبطة بحساب المستخدم فقط. |
| التكلفة | تبدأ جميع المراحل بالمصادر الحالية أو المجانية، ولا يضاف مزود مدفوع أو بطاقة كشرط. |
| قابلية التفسير | كل مستوى أو إشارة يوضح مصدره وإطاره ووقت اكتشافه. |
| السلامة | المخرجات تحليلية وتعليمية؛ لا توجد أوامر تداول حقيقية أو ضمانات نتيجة. |

## القرار المقترح الآن

ابدأ بالمرحلة **P0: بطاقة حالة بيانات الأصل + ملف رمز المعادن والفوركس**. هذه الخطوة صغيرة نسبيًا، وتمنع الالتباس بين السعر الحي والاحتياطي، وتبني قاعدة سليمة لكل تحسين لاحق في البنية والتنبيهات والمخاطرة.
